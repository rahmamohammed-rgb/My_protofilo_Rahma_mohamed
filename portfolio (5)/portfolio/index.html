Selected work

Three front-end builds: the problem, the tools I used, and what the client gets.

Bakery: single-page business site

HTML5 · CSS3 · Flexbox · Google Maps embed

The problem. A local bakery had no online presence, so customers couldn't see the menu or find the shop, and a site that broke on phones would have lost them right away.

What I used. Semantic HTML5, Flexbox layouts, custom media queries at 576px, 768px and 992px, and a live Google Maps frame for the location.

The result. One fast page with menu, story, location and contact that reflows cleanly on every screen, so customers find the shop and reach the owner in seconds.

View live site

Fokir: multi-section portfolio layout

HTML5 · CSS3 · reusable classes

The problem. A personal brand needs one page that shows services, projects and a way to get in touch, without being messy or hard to update later.

What I used. HTML5 with headings in order and labelled form fields, and CSS organised around reusable classes and consistent spacing, with a fixed navigation bar.

The result. A clean, easy-to-scan site where visitors jump straight to services or contact, and new sections can be added without rewriting the stylesheet.

This portfolio

HTML5 · CSS3 · vanilla JavaScript · GitHub Pages

The problem. Templates make every developer's site look the same, and heavy page builders load slowly on a phone, which is where most clients first look.

What I used. Hand-written HTML, CSS and JavaScript, custom colour tokens, a saved light and dark theme, reduced-motion support and a compressed WebP image.

The result. A distinctive site that loads fast on mobile, is comfortable to read in any lighting, and works with a keyboard, published live on GitHub Pages.
