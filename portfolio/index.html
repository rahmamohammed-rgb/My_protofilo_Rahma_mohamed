About me

I'm Rahma, a front-end developer and Systems & Computer Engineering graduate from Al-Azhar University, where I finished third in my class.

Engineering taught me to break a problem into parts and solve it properly; front-end is where I get to make that work visible. I write semantic HTML, layout with Flexbox and Grid, and build component-based interfaces in React with clean state management.

I'm currently training in React with the Digital Egypt Pioneers Initiative (DEPI), and I build a new project with every concept I learn — because a page that only works on my laptop isn't finished.

I work well with feedback, keep clients updated as things progress, and care about the small details: spacing that stays consistent, layouts that hold up at 375px, and buttons that respond the way you expect.
